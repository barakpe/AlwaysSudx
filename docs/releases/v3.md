The wrapper uses fixed 0/32/64 slices for the existing 32+32+17-byte protocol. No C or protocol change. K5 hard1 passes with unchanged application cycles.

```text
Mapped LEs: 23,949 -> 17,199. hard1 application cycles remain 603.
This checkpoint measured area and correctness; standalone Fmax was not measured.
```

This release preserves a **source and measurement milestone**. No full-system
bitstream was built for this version; no v5 binary is presented as this hardware.

the verified programming files. GitHub provides the exact tagged source archives.
